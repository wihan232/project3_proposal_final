This final project will be my first real attempt at creating a functional deployed site that showcases everything that I learned in this course. If executed successfully, the webpage could be deployed to professionally demonstrate my capabilities of seeing a web project through from start to finish. Completion of this should mark a big milestone in my learning.

The webpage serves to inform its visitors about the Ad-Hominem Fallacy, which is one of the most prevalent argumentative shortcuts that people use in modern day. It is used everywhere. From the people closest to us, like our friends and family, to others that we would never meet physically, like social media users--all of them have used or are exposed to communication involving this fallacy. Knowing about the existence of this logical shortcut will help people understand whether they base their logic on sound principles.
